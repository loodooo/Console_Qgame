# Qgame

A very simple game for the windows console, this was a college project that i had to show of in class, programmed in a single overnight session the same day it was due

### Dependencies

* SixLabors.ImageSharp (3.1.12)
> UNSURE IF THIS IS EVEN USED IN FINAL VERSION
* Windows 10 / 11, with windows console only
> doesnt work with legacy console, but uses some features of "older" windows console should work fine other than wont set itself into fullscreen on modern console versions
